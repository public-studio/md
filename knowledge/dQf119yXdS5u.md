# KAINS-VPN接続ガイド

## 概要
KAINS-VPNを使用すると、自宅や出張先などの学外ネットワークから、学内にアクセスが制限されたWebシステムやサーバーを利用できます。

- 対象：Windows 11を使用したFortiClient VPNの接続手順
- VPNの基本設定はWindows・macOS共通（OS固有の項目を除く）
- 原資料：学術メディア創成センター・パソコン相談カウンター、2023年12月7日

## 初期設定（初回のみ）
1. **FortiClient VPN**を起動する。
2. 承諾画面が表示された場合は、チェックを入れて「承諾します」をクリックする。表示されなければ次へ進む。
3. 「VPN設定」をクリックする。
4. 「新規VPN接続」で以下を設定し、「保存」をクリックする。

| 項目 | 設定値 |
| --- | --- |
| VPN種別 | SSL-VPN |
| 接続名 | KAINS-VPN |
| 説明 | 空欄 |
| リモートGW | `vpn.kains.kanazawa-u.ac.jp` |
| 認証 | ユーザ名入力（ユーザ名を保存する方式） |
| IPv4/IPv6デュアルスタックアドレスを有効化 | Windowsではチェックする。macOSにはこの項目がない |

## 接続手順
1. VPN接続先として「KAINS-VPN」を選択する。
2. 自分の**KAINS ID**（`****@kains.net`形式）とパスワードを入力する。
3. 「接続」をクリックする。
4. 「VPN接続済み」と表示されたら接続完了。

## KAINS ID・パスワードを忘れた場合
[KAINS Account Center](https://account.kains.kanazawa-u.ac.jp/)で確認・再設定する。

## 接続上の制限
VPN接続は**1アカウントにつき1接続のみ**。同じアカウントで複数の接続はできない。
