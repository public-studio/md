# AI Studio 共通スキル目次

スキル本文は、必要な場合にだけ各固定Markdown URLから取得してください。登録したスキルはこの目次へ自動反映されます。

- [ボット作成](https://raw.githubusercontent.com/public-studio/md/main/skills/builtinbot01.md) — 自由な用途のチャットボットを設計して登録する
- [スキルを作るスキル](https://raw.githubusercontent.com/public-studio/md/main/skills/skillmaker01.md) — 再利用可能なスキルMarkdownを作成して登録する
- [ボット改善](https://raw.githubusercontent.com/public-studio/md/main/skills/evolvebot001.md) — 自分または別ボットのMarkdownを同じIDで更新する
- [スキル改良・コピー](https://raw.githubusercontent.com/public-studio/md/main/skills/skillrev0001.md) — スキルの同一ID更新または別IDへの派生を行う
- [ナレッジソース・公開DB](https://raw.githubusercontent.com/public-studio/md/main/skills/knowledg0001.md) — 既存のナレッジ資料と公開DBを適切に使い分ける
- [保存・起動URL](https://raw.githubusercontent.com/public-studio/md/main/skills/saveurl00001.md) — 生成Markdownを登録画面へ渡し、固定URLと起動URLを案内する
- [3行要約](https://raw.githubusercontent.com/public-studio/md/main/skills/9rs04G0wHXEP.md) — 長い文章を3つの箇条書きで簡潔にまとめる
- [Codex Factory スキル検証 20261118 改名](https://raw.githubusercontent.com/public-studio/md/main/skills/LM5a70JJvBgi.md) — 改名後の説明を再取得するテストスキル
- [Codex Factory動作確認スキル 20261118 更新](https://raw.githubusercontent.com/public-studio/md/main/skills/kWb-VisTCqyP.md) — 更新後の説明・共通目次反映を確認
- [Codex Factory動作確認スキル 20261118 更新 (コピー)](https://raw.githubusercontent.com/public-studio/md/main/skills/v81l4wBkbJb3.md) — 更新後の説明・共通目次反映を確認
- [Codex production smoke test](https://raw.githubusercontent.com/public-studio/md/main/skills/QJu81AESeL6q.md) — Temporary skill used to verify the one-click registration and receipt flow.
- [P12 本番更新テスト 2026-11-19](https://raw.githubusercontent.com/public-studio/md/main/skills/jBThIob-G8G5.md) — P12本番ブラウザー更新、固定URL・revision・共通目次の確認用テストデータ。
- [スキルを作るスキル (コピー)](https://raw.githubusercontent.com/public-studio/md/main/skills/rQIDARdpIbmX.md) — 再利用可能なスキルMarkdownを作成して登録する
