# AI Studio 共通スキル目次

SYSTEMはAI Studio公式の読み取り専用スキル、USERは利用者が作成・更新するスキルです。本文は必要な場合だけ公開Markdown URLから取得してください。SYSTEMを更新したい場合はUSERとしてコピーしてください。

## SYSTEM

- [Webアプリ用DB操作](https://raw.githubusercontent.com/public-studio/md/main/skills/system/syswebdb0001.md) — Webアプリ用公開DBのAPIと安全なデータ操作を案内する
- [スキルを作るスキル](https://raw.githubusercontent.com/public-studio/md/main/skills/system/skillmaker01.md) — 再利用可能なスキルMarkdownを作成して登録する
- [スキル改良・コピー](https://raw.githubusercontent.com/public-studio/md/main/skills/system/skillrev0001.md) — スキルの同一ID更新または別IDへの派生を行う
- [ナレッジソース・公開DB](https://raw.githubusercontent.com/public-studio/md/main/skills/system/knowledg0001.md) — 既存のナレッジ資料と公開DBを適切に使い分ける
- [ナレッジソース操作](https://raw.githubusercontent.com/public-studio/md/main/skills/system/sysknow00001.md) — 公開Markdown資料の参照・登録・安全な更新を案内する
- [ボット改善](https://raw.githubusercontent.com/public-studio/md/main/skills/system/evolvebot001.md) — 自分または別ボットのMarkdownを同じIDで更新する
- [ボット作成](https://raw.githubusercontent.com/public-studio/md/main/skills/system/builtinbot01.md) — 自由な用途のチャットボットを設計して登録する
- [保存・起動URL](https://raw.githubusercontent.com/public-studio/md/main/skills/system/saveurl00001.md) — 生成Markdownを登録画面へ渡し、固定URLと起動URLを案内する
